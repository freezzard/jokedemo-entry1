A Python program that writes one original one-line joke about working beside AI coding agents to `/output/entry.txt`. The joke is the winner of a 20-candidate local pairwise tournament judged against the quest's own brief (on-subject, laugh, truth, economy, freshness): it went 3-0 with 2.50 points. The program is deterministic and offline — standard library only, no network — and every run writes exactly the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
